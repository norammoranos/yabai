# Локальная сборка форка

Текущая адаптация рабочего стола находится в `codex/macos-desktop`. При `YABAI_DESKTOP_CONTROLS=1` тот же процесс yabai обрабатывает Caps→F18, короткий Caps→Escape, локальные номера столов и Tab на мониторе под курсором, Option+три пальца, мышиный swap/drop и перенос у края после двух секунд. `window_insertion_point largest` делит крупнейшую плитку; `auto_balance off` сохраняет сделанные разрезы. Протокол изменения окон остаётся штатным IPC yabai.

Обзор — нативный Mission Control, вызываемый Caps+Control+O или системным жестом четыре пальца вверх. Три пальца горизонтально также обрабатывает macOS. Собственные панели, захват изображений и обработка обычного четырёхпальцевого свайпа из форка удалены. Нативные жесты нужно выбрать в System Settings; установка бинарника сама их не меняет. Option+три распознаёт только явно удерживаемый Option, сбрасывает движение при смене контактов/сне и не превращает обычный свайп в перенос.

На macOS 27 старый synthetic Dock swipe не активировал стол и возвращал ложный успех. SIP-enabled `space --focus` теперь посылает один нативный shortcut «Перейти на Рабочий стол N» через HID event source и проверяет фактический Space ID. Промежуточные столы не перебираются; номера macOS считаются без fullscreen Spaces, локальные Caps номера сохраняются. В System Settings → Клавиатура → Сочетания клавиш → Mission Control включите прямые переходы на существующие столы 1…9. При отключённом shortcut IPC возвращает понятную ошибку. Переход на fullscreen/номер выше 9 этим backend не поддержан. Control+стрелки можно оставить для штатного соседнего перехода, но форк их больше не перебирает.

Живая регрессия: `python3 tests/native_space_focus_smoke.py`. Она временно выбирает первый, последний и пустой стол текущего экрана, проверяет конечный ID и неизменность других экранов, затем возвращает первоначальный выбор. Запускать без одновременного физического переключения. На встроенном экране проверки 1→7, пустого стола и возврата прошли за ~0,3 s каждый; пользователь отдельно подтвердил Caps и трёхпальцевый свайп.

Профиль и LaunchAgent находятся в `os_settings/macos/configs/yabai` и `macos/scripts/yabai-desktop.py`. SIP включён, Accessibility установленного бинарника подтверждён после повторных сборок. Автоматическое возвращение девяти Spaces при отключении экранов, minimum overflow и постоянный верхний слой floating не объявляются реализованными. Проверка ввода: `xcrun clang -Wall -Wextra -std=c11 tests/desktop_gesture_test.c -o /tmp/yabai-desktop-gesture-test && /tmp/yabai-desktop-gesture-test`; физические жесты проверяются на устройстве.

Ветка `codex/macos-sip-enabled` основана на стабильном теге `v7.1.25`, а не на движущемся `master`. `origin` — собственный GitHub-форк; `upstream` — `asmvik/yabai`. Это позволяет редактировать исходники и отдельно принимать upstream изменения.

```sh
YABAI_SIGNING_IDENTITY='имя постоянного сертификата' ./scripts/install-local-source.sh
~/.local/bin/yabai --version
~/.local/bin/yabai --check-accessibility
```

Скрипт собирает оптимизированный универсальный бинарник, подписывает его, проверяет подпись и устанавливает в `~/.local/bin`. Прежний бинарник и сведения о сборке сохраняются в `~/.local/state/yabai-source`. Для повторных сборок используйте тот же сертификат и путь: иначе macOS может потребовать выдать Accessibility заново. `make install` upstream выполняет только сборку; установку выполняет этот скрипт.

`--check-accessibility` — добавленная команда форка: код 0 означает предоставленный доступ, код 3 — отсутствие доступа. Она не показывает запрос разрешения, не запускает event loop, не читает конфиг и не размещает окна. Перед запуском самого менеджера доступ нужно предоставить через системные настройки macOS.

SIP сохраняется. Скрипт не запускает yabai, не создаёт LaunchAgent, не загружает scripting addition и не меняет sudoers. Не запускайте одновременно два оконных менеджера. Раскладка BSP работает с нативными Spaces macOS; виртуальные рабочие столы, обзор и жесты другого менеджера не переносятся автоматически. Установка сама по себе не даёт постоянный верхний слой сторонним окнам.
